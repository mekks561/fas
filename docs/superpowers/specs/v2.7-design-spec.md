# v2.7 "深空觉醒" (Deep Space Awakening) 设计规范

## 1. 版本概览
*   **版本号**: 2.7.0
*   **核心理念**: 融合 2026 年 WebGPU 与神经网络技术，实现从“线性空战”到“动态宇宙模拟”的跨越。
*   **设计配比**: 60% 宇宙探索与生态 + 40% 硬核物理拟真战斗。

## 2. 五大新增子系统

### 2.1 跃迁式星区架构 (Jump-gate Sector Architect)
*   **技术栈**: WebGPU 驱动的 GPU-Driven PCG (程序化内容生成)。
*   **实现**: 
    *   宇宙由多个独立生成的“星区”组成，通过“跃迁门”连接。
    *   每个星区拥有独立的视觉主题（星云颜色、光照参数）和资源密度分布。
    *   **2026 技术点**: 利用 GPU Work Graphs 实时生成数以万计的陨石和空间站细节，无需 CPU 干预。

### 2.2 全球派系声望网络 (Global Faction Neural Network)
*   **技术栈**: 基于 WASM 的轻量化神经网络推理。
*   **实现**:
    *   三大宏观派系：贸易联盟、拾荒者、帝国卫队。
    *   **神经网络决策**: NPC 派系会根据全星系的资源流向和玩家行为（声望值）动态调整策略。例如：若玩家在某区大量击杀贸易船，全星系的保险费用会上涨，派系巡逻队会向该区集结。

### 2.3 动态资源与采矿系统 (Dynamic Resource & Mining)
*   **功能**:
    *   引入可采集的物理陨石。玩家需通过精准控制采矿激光束（受物理反馈影响）提取矿物。
    *   **经济闭环**: 采集的资源可在星区空间站出售。物价受 NPC 贸易行为实时波动影响。

### 2.4 极致物理损毁与质心演算 (Extreme Damage & CoM Physics)
*   **技术栈**: WebGPU Compute Shader + 实物碰撞检测。
*   **实现**:
    *   **几何变形**: 飞船受击处产生真实的网格撕裂和金属扭曲。
    *   **质心偏移 (CoM)**: 关键部位（如机翼、引擎仓）损毁后，飞船质心会实时计算偏移。玩家必须手动调节姿态感应器或代偿推力，否则飞船会发生难以控制的自旋。
    *   **功能剥落**: 武器挂架被击毁会导致对应的逻辑武器槽失效。

### 2.5 战术体积星云环境 (Tactical Volumetric Nebula)
*   **技术栈**: 实时体积云模拟 (Real-time Volumetric Rendering)。
*   **功能**:
    *   星云不仅仅是视觉特效，它具有真实的物理属性。
    *   **战术价值**: 进入星云可获得隐身加成（雷达信号衰减），但会导致推进器过热速度加快和制动距离增加。

## 3. 2026 先进技术要求
1.  **WebGPU Next**: 全面弃用 WebGL 2.0，利用 Compute Shader 处理复杂的物理损毁计算。
2.  **Neural NPCs**: 引入轻量化模型处理派系战略决策，确保 NPC 行为不再是简单的状态机。
3.  **Real-time Sound Ray-tracing**: 基于物理环境的音效反射，增强战斗沉浸感。

## 4. 实施路线图
1.  **Phase 1**: 搭建跃迁门基础架构与星区生成器。
2.  **Phase 2**: 集成 WebGPU 物理损毁引擎。
3.  **Phase 3**: 部署神经网络声望系统与动态贸易逻辑。
