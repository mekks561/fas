# v2.8 "觉醒舰队" (Awakening Fleet) 设计规范

## 1. 版本概览

- **版本号**: 2.8.0
- **核心理念**: 从"孤胆飞行员"升级为"舰队指挥官"——让 NPC 不再是各自为战的散兵，而是能编队协同、进化学习的战术集群；引入可被逐级拆解的巨型母舰作为高价值目标；把星图跃迁从"点一下就走"做成有沉浸感的跨星系航行体验。
- **设计配比**: 50% 舰队战术 AI + 30% 母舰 Boss 战 + 20% 星图跃迁交互。
- **承接 v2.7**: v2.7 已落地 WebGPU 损毁、星区跃迁、派系神经网络骨架。v2.8 在这些骨架上长肉，不推翻已有架构。

## 2. 三大新增子系统

### 2.1 集群战术网 (Swarm Intelligence)

- **目标**: NPC 编队协同 + 进化式行为学习。
- **现有基础**:
  - `AINPCController`：单 NPC 决策循环（`updateAIAsync` 逐个 `decideWithAI`），无编队概念。
  - `StrategicAICore.NeuralDecisionNetwork`：已有加权神经元（aggression / resource_need / player_threat），是进化学习的天然载体。
- **新增设计**:
  - **编队管理器 (`SquadManager`)**: 把同派系 NPC 按 3–6 架编为小队，共享 `SquadTacticalState`（目标点、威胁等级、集火目标）。队长决策、队员跟随 + 侧翼包抄。
  - **战术队形**: 楔形（突击）、环形（防御）、纵队（追击）三种队形，由队长根据威胁等级切换。
  - **进化式权重调整**: `NeuralDecisionNetwork` 的权重在每次战斗后根据战果（击杀/损失）做梯度式微调，跨局持久化到 `GameDatabase`。弱派系会逐渐学会规避强玩家。
  - **通信广播**: 小队内 NPC 受伤/阵亡时广播告警，附近友军响应（救援 or 撤退）。
- **约束**: 每帧编队计算开销 ≤ 0.3ms（百架级 NPC），进化学习只在战斗结算时跑（不进主循环）。

### 2.2 巨型母舰 (Capital Ships)

- **目标**: 多级损毁判定的大型旗舰实体，作为星区 BOSS / 派系旗舰。
- **现有基础**:
  - `VoidLordBoss` 继承 `Enemy`，已有 3 阶段血量转换（70% / 30%）。
  - `WebGPUDamageSystem` + `MeshTearingSystem`：顶点级网格撕裂、功能性损毁。
- **新增设计**:
  - **子系统损毁模型**: 母舰拆为 5 个可独立损毁的子系统——舰桥（指挥）、主引擎（机动）、武器阵列（火力）、反应堆（能量/自毁）、护盾发生器（防御）。每个子系统有独立血量和功能失效逻辑。
  - **多级阶段**: 不再只是血量阶段，而是"子系统损毁组合"驱动行为变化：主引擎损毁 → 机动下降 70%；舰桥损毁 → AI 降智（失去编队协同）；反应堆损毁 → 5 秒后自毁爆炸（范围伤害）。
  - **体量与渲染**: 母舰体积为普通敌机的 40–80 倍，使用 `InstancedRenderer` 挂载副炮炮塔，主体用 PBR 材质 + `MeshTearingSystem` 做局部撕裂。
  - **掉落与奖励**: 击毁母舰掉落大量资源 + 稀有舰体涂装，触发派系声望大幅变动。
- **约束**: 母舰同屏上限 1 艘（性能），子系统损毁判定走 `WebGPUDamageSystem` 的 hit-area 映射，不新增独立物理引擎。

### 2.3 跨星系跃迁流 (Galactic Jump Flow)

- **目标**: 把星图跃迁从功能型点击升级为有沉浸感的航行交互。
- **现有基础**:
  - `StarMap.tsx`：已有星区节点、当前星区、战略事件展示。
  - `GalaxyManager` / `JumpGate` / `SectorManager`：跃迁逻辑已通。
- **新增设计**:
  - **星图深度交互**:
    - 节点悬停显示星区详情（派系控制、资源丰度、威胁等级、驻泊舰队）。
    - 可选中转星区规划多跳航线，显示总跃迁时间与燃料消耗。
    - 派系控制区用颜色叠加，敌方控制区跃迁需消耗"跃迁许可"或强行突破（触发遭遇战）。
  - **跃迁过场动画**:
    - 跃迁启动时画面拉伸 + 星空拖尾（PlayCanvas post-processing），持续 2–3 秒。
    - 跃迁中显示航线进度条 + 途经星区名，可跳过。
  - **遭遇战触发**: 跨派系控制区跃迁有概率触发伏击（母舰 or 编队），把"飞过去"变成"打过去"。
- **约束**: 星图 UI 不阻塞游戏主循环（打开时 `setGamePaused(true)`），跃迁动画用现有 `VisualEffectSystem` 实现，不引入新 shader 管线。

## 3. 技术约束与复用

1.  **不新增重型依赖**: 进化学习复用 `StrategicAICore` 的神经网络结构，母舰复用 `Enemy` + `WebGPUDamageSystem`，星图复用 `StarMap.tsx`。
2.  **性能红线**: 百架 NPC 编队 + 1 艘母舰同屏时，主线程帧时间增量 ≤ 2ms（编队计算走 `SectorManager.update` 的现有 tick）。
3.  **存档兼容**: 母舰损毁状态、神经网络权重持久化到 `GameDatabase`，老存档缺字段时走默认值降级。

## 4. 实施路线图

1.  **Phase 1 — 集群战术网**: `SquadManager` + 队形切换 + 战术广播，先跑通"3 架编队打玩家"。
2.  **Phase 2 — 巨型母舰**: 子系统损毁模型 + `VoidLordBoss` 迁移为母舰原型，验证多级阶段行为。
3.  **Phase 3 — 跨星系跃迁流**: 星图 UI 深化 + 跃迁动画 + 遭遇战触发，打通完整航行链路。
4.  **Phase 4 — 整合与进化**: 神经网络权重持久化 + 派系声望联动母舰出现频率，全链路联调。

## 5. 验收标准

- 编队：同派系 ≥3 架 NPC 会自动编队，队长阵亡后剩余 NPC 重新选队长并切换队形。
- 母舰：击毁 5 个子系统中的任意 3 个可导致母舰瘫痪；反应堆单独击毁触发自毁爆炸。
- 星图：可规划 ≥2 跳的航线并执行跃迁；跃迁过场动画可跳过；跨派系跃迁有概率触发伏击。
- 回归：tsc 0 错、529+ 测试全绿、`pnpm build` 通过。
